📱 Help & Installation

Install Elhavryn's Phasmophobia Field Guide for free on your favorite device!

Android Phones

  1. Open the guide in Google Chrome.
  2. Tap the three-dot menu.
  3. Select "Install and create shortcut".
  4. Choose Install app and confirm.
  5. Open the ghost icon on your phone!

iPhone and iPad

  1. Open the guide in Safari.
  2. Tap the Share button.
  3. Choose "Add to Home Screen".
  4. Enable "Open as Web App" if shown.
  5. Tap Add to finish.

Windows Computers

  1. Open the guide in Google Chrome.
  2. Click the Install icon in the address bar, if available.
  3. Alternatively, find the install option in Chrome's menu.
  4. Confirm installation.
  5. Launch your new Field Guide app!

👻 Offline access: Open the guide while connected to the internet first so its content can be saved for offline use.
